# lab3-report-log —— AI 日志与报告规范

## AI 交互日志（logs/AI_LOG.md）

- 字段：日期时间 | 交互目的 | Prompt 摘要 | 产出 | 可用性 | 人工修改类型 | 备注。
- 可用性三档：直接可用 / 需修改后可用 / 不可用（用于统计首次通过率）。
- 人工修改类型：接口 / 位宽 / 时序 / 功能bug / 优化 / 无。
- **覆盖计数（报告硬指标）**：T2 上下文包构建 ≥1、T3 脚本化执行 ≥3、T4 约束迭代 ≥4（2 轮×方案+验证）、T5 故障调试 ≥2。
- 每轮交互后立刻追加，不要攒到最后补。

## 调试日志（logs/调试日志.md）

- 只记事实：完整报错日志、可验证现象（"数码管显示 E 而非 3""串口收到 0xBB 03 0xEE"）、复现步骤、定位结论。

## 时间构成分析（报告必答，评优依据）

- 识别时间 = 上位机发帧到收结果的毫秒数。
- 构成：串口传输（波特率×帧长）vs 板上推理（推理核延迟）。
- 115200 下 784B ≈ 68ms；1Mbps ≈ 7.8ms；推理核 8~16 MAC 展开 ≈ 13µs~几十µs。
- 至少一项优化及其实测效果 + 一张「优化前→优化后」对比表。

## 报告结构（6~12 页）

AI 交互日志（过程分主体）+ 系统方案与决策论证 + 识别时间构成分析与优化 + 问题复盘与心得（独立撰写）+《AI 使用声明》。
